## Download

| Platform | File |
|---|---|
| macOS: Apple Silicon (M1 and later) | `YT-Downloader-macOS-AppleSilicon.zip` |
| macOS: Intel | `YT-Downloader-macOS-Intel.zip` |
| Windows 10 / 11 | `YT-Downloader-Windows.exe` |

No Python or ffmpeg needed. Everything is bundled. Requires macOS 15 (Sequoia) or later, or Windows 10 / 11.

**macOS:** unzip and drag **YT Downloader** to Applications. The app isn't code-signed, so the first time, right-click it → **Open** → **Open**. If macOS says the app is "damaged", run `xattr -cr "/Applications/YT Downloader.app"` in Terminal.

**Windows:** double-click the `.exe`. If SmartScreen appears, click **More info** → **Run anyway** (the app isn't code-signed).

For every quality option to be available, install [deno](https://deno.com) or Node.js (YouTube requires a JavaScript runtime).

> ⚠️ **Only download content you own or have explicit permission to download.** Downloading other content may violate YouTube's Terms of Service and copyright law.
